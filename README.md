# @suresilly

An easy-going Instagram page of tiny truths. Each post is warm paper, a soft serif, one highlighted phrase and a small green donkey.

- **Twice a day:** a list or a short story in the morning, and a one-liner in the evening.
- **You approve every post on Telegram.** Silence for an hour means it posts.
