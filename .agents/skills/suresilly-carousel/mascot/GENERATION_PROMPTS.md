### Check these three before importing

Costume sheets are the ones most likely to drift into someone else's character. Before you
import, look for: a recognisable emblem or logo, a mask that matches a known character, a
colour combination that reads as an existing hero, or any writing on the costume.

sage green, cream and charcoal. Keep the pose the same."*

## Sheet 20 — Two Sillys

**The most useful sheet in this file.** Every other pose is Silly on his own, but your whole
subject is two people. This one lets you draw the dynamic instead of describing it.

Silly stays green. The other donkey is grey, so the two read apart instantly at feed size —
and so a slide can say "you" and "them" without a word of explanation.

Two figures make a wide image, so the renderer sizes these by width automatically.

```
Use the attached image as the exact character reference. Same donkey, same colours, same
flat vector style, same thick black eyebrow bar, same curly black mane.

Make ONE image as a 3 x 2 grid: 3 across, 2 down. Six scenes, evenly spaced, each one
complete and fully inside its own cell.

EACH CELL CONTAINS TWO donkeys interacting with each other. Both are full-body, seen from
the side, on a level ground line.

They are identical in every way EXCEPT body colour:
- The FIRST donkey is the green one from the reference image (#3C965A). This is Silly.
- The SECOND donkey is a soft neutral GREY (#757A77). Everything else about him is the same
  as Silly: same shape, same cream muzzle, same cream belly patch, same black curly mane,
  same thick black eyebrow bar, same black hooves. Only the body colour differs.

Background: flat solid magenta #FF00FF, edge to edge. No shadows. No borders.
No text, no letters, no numbers, no labels, no captions, no speech bubbles.

Scenes:
1. One reaches out a hoof while the other turns away with folded arms. The pursue and withdraw pattern.
```

## Import one sheet at a time

Run each command on its own. Do not put the names in a shell array and loop — zsh arrays
start at 1, not 0, which silently shifts every sheet's names by one. The importer now refuses
`--grid` without `--names`, and checks the count, but it cannot detect names that are simply
in the wrong order.

After importing, open `mascot/poses.json` and check the tags for each new pose. Tags are what
a slide's `**Mascot:**` brief is matched against.

## If a sheet comes back wrong

| Problem | What to say in a follow-up message |
|---|---|
| Text appeared | "Remove all text, letters and numbers. Keep everything else the same." |
| Legs cut off | "Show the complete body of every character. Nothing cut off by the edges." |
| Background not flat | "Make the background one flat solid magenta #FF00FF with no shadows." |
| Character drifted | Start again. Attach the master. Do not continue the old chat. |

Never keep a sheet with text on it. The import will reject it anyway.
