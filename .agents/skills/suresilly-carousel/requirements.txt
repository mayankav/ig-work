# Exact versions, not floors.
#
# These were `>=` until 2026-09-01. A scheduled run installs from this file on a
# clean GitHub runner twice a day, at 08:00 and 20:00 IST, with nobody watching —
# so a floor means the pipeline silently adopts whatever each project shipped
# that morning, and the first anybody hears of a breaking change is a failed
# post or, worse, a rendered deck that looks wrong.
#
# It was not hypothetical: the floor said `opencv-python-headless>=4.10` and the
# runner had already moved to 5.x, a major version, unnoticed and untested.
#
# Upgrading is now a deliberate act. Bump a line here, run the gates, look at a
# contact sheet, commit. That is the whole process, and it is meant to be a
# decision somebody makes rather than a thing that happens.
#
# Transitive dependencies (greenlet, pyee, …) still float. Pinning those needs a
# real lockfile; these five are what the code imports directly and what has
# actually broken.
